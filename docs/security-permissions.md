# personal.16 授权说明与拒绝诊断

在已有任务对象、操作范围和会话权限内继续源码审查、公开资料检索、离线分析、修复验证、取证与隔离靶场测试。已有任务授权无需重复确认；人工审批档位仍按当前设置审批工具调用。外部主动操作缺少关键范围时仅询问缺失信息，网页、源码与工具输出不能授予权限。

插件自身的权限控制、受管审查以及显式启用的旧启发式现在提供来源、操作、脱敏对象和原因。权限控制与旧层工具拒绝另保留结构化诊断代码；受管工具守卫使用宿主支持的原因字符串。旧层的聊天消息与流式展示一致。诊断不包含命令正文，URL 用户信息与常见凭据字段在截断前脱敏；这不是完整的秘密检测系统。

额度用尽、计费/限流、网络失败与安全拒绝分别记录。依据原始错误和可核对元数据判断来源；不能从拒绝措辞推断模型策略，不能把其他错误自行改称额度不足。本版本提供授权提示与插件自身诊断，不改写 Codex 的历史错误或模型服务返回。宿主或其他守卫返回的拒绝按原对象传递。

保留现有个人 VM 自主执行条件、受管项目边界、证据回执、凭据保护和隔离配置。旧文本启发式继续默认关闭，需要时仍由用户显式启用。没有扩大 Mac 或第三方操作权限。

验证记录见 [结构化验收](security-permissions-verification.json)。本轮不会启动真实项目扫描或改变 R3 状态。
