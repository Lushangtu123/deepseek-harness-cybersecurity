# VM 联合安全审查的受管适配器

此前 .5 修复脱敏文件大小和转义摘要分页边界；personal.7 新增本地 ZAP，当前版本与恢复验收见[统一状态](current-status.md)。

“联合安全审查”保留独立预设，仅更新 VM。日常、受限审查和原版预设继续保留。用户在安全审计页保存项目范围后，模型通过 `redteam_joint_review` 选择步骤，使用同一个任务 ID 查询、等待、取消和分页读取报告。

| 步骤 | 本轮能力 | 边界与结果含义 |
| --- | --- | --- |
| Semgrep / Trivy | 固定脱敏源码副本的静态检查 | 命中继续待验证；解析缺口保留 |
| ZAP | 已授权 VM 回环应用的短时爬取与被动基线 | 刷新不自动勾选；复用私有会话配置；HTTP 证据与源码副本分开，运行版本关系未证明 |
| Kali | 专用 Kali 中的离线 Bandit | 单独保存 Python 副本交接授权 |
| REA＋reverse-skill | 固定版本路由及 JavaScript/TypeScript 应用静态图 | 单独授权；禁网、只读输入、非 root 容器；不执行源码；图结构证据不等于漏洞 |
| PentAGI | 独立临时实例中的模型辅助审查 | 单独授权向既有 DeepSeek 服务交接脱敏源码；在隔离工作容器执行命令，结果是未验证的模型分析 |

REA 本轮使用已安装 6.8.0 的 `analyze-javascript-application`，不是 Wakaru 源码恢复，也没有把所有 REA/Ghidra 逆向操作开放给模型。二进制仍在默认副本排除项中。reverse-skill 固定在 `cab634bd855fc287f6e420c1f36fd1a6b9245960`，校验路由脚本和配置；路由输出中的指令不自动执行。

PentAGI 沿用已安装的 `cffed9485aa1cca70762cd08a57ac62a80406258` 镜像，每个受管子任务创建独立临时数据库和核心实例，不使用原版实例的任务、数据库或 API token。工作容器只挂载交接副本，禁网、非 root、删除全部 capabilities、限制内存/进程/临时磁盘并设定容器内超时。Docker API 代理重建固定容器参数，仅允许所属工作容器及其 exec；真实 Docker socket 和模型密钥不交给模型或工作容器。

模型网关只转发到现有 DeepSeek 服务，固定 `deepseek-flash`，单任务最多 **16 次请求、每次最多 2048 输出 tokens、请求体最多 256 KiB**。发送前持久预留次数，失败或结果未知不退还。此预算不是货币金额硬上限；主聊天费用另计。模型网关可以发送脱敏源码，授权前应核对项目脱敏规则。

受管任务先保存请求 ID，再启动子任务。相同请求复用原记录，后台重启不自动重跑；停止未确认时阻止新联合任务。取消会核对所属资源清理，不把“已发出停止请求”当作停止成功。

`report` 的 `artifacts` 段另含 ZAP 的目标 origin、认证前后核对、扫描状态和运行版本未证明标记；同时保存 REA 图结构摘要、reverse-skill 路由身份、PentAGI 未验证结论摘要及证据哈希。完整原始产物留在 VM 私有任务目录；分页摘要明确截断。`findings` 继续保存工具命中，不会因为模型下结论而自动确认漏洞。身份认证、越权、业务逻辑、架构和未选工具不属于自动完成项。

当已声明子任务全部结束并保留非空结果时，控制器主动结束这次私有流程，保留完成依据；不等待额外父级自动摘要。此处完成指已收集子任务结果，不是模型整体自主渗透或漏洞复现。存在待运行子任务、空结果或需要用户输入时，不能按此规则完成。预算耗尽会保留 partial 及已取得证据。
