# VM 安全工作区计分规则与回执

计分器按实际得分点 ID 读取默认分、启用状态、去重口径和上限。无代码点各自计分，显式配置相同规则号的档位继续共享该规则。旧调用在没有可解析 ID 时可以按代码读取规则。面板、报告与攻击链共用判定。无代码点按其已存规则计分后，历史同服务命中的汇总可能重新计算，命中原始记录全部保留。

仓库中的 G1 与 G3 要求取最高权限和遵守累计上限。当前实现先选最高档，再按规则上限计入完整记录。仓库未收录关于最高档超限后回退旧档的原始条款。本次沿用该顺序。上限 10 分时，先记 5 分再记 11 分，最高档超过上限，项目分数会从 5 变为 0。

写入回执提供 `score_change.before`、`after` 与 `delta`。旧命中从计入变成排除时列入 `demoted_hits`，附排除原因。重新计入的旧命中列入 `promoted_hits`。已处于排除状态且仍排除的旧记录不重复列入变化。项目级变动可能来自同一规则内的不同服务。停用和自建的命中正确标为未计分。

一次 SQLite 写事务覆盖插入和回执计算。前后两次评估共用同一份规则和记录快照，写入前的评估仅排除本次新增命中。计算失败时新增命中回滚。该回执描述写入当时的结果，后续规则编辑仍可改变项目汇总。
