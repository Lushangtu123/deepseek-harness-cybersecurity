# VM Harness 模型工具的计分上限状态

得分列表和攻击链现在提供 `cap_status`。模型可直接引用状态，无需由空值推断。

| 状态 | 含义 | 实际上限 |
| --- | --- | --- |
| disabled | 得分点停用，命中不计分 | null |
| unlimited | 得分点启用，规则不设上限 | 0 |
| limited | 得分点启用，按有效上限执行 | 正数 |
| unknown | 攻击链中的历史命中缺少所属得分点 | null |

得分列表保留原配置 `cap`，实际生效值为 `effective_cap`。攻击链命中返回 `rule_cap`。上限状态描述得分点，是否计入以命中的 `counted` 和 `exclusion_reason` 为准。例如启用的有限规则下，某条命中仍可能因达到上限而排除。项目总分、页内得分和共享规则冲突的计算沿用现有实现。
