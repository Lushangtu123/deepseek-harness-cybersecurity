| 请求 | 当前结果 |
| --- | --- |
| ordinary 计划 | 记录普通模式和 R3 门槛；固定扫描器尚缺 R3 验收，当前可执行步骤为空 |
| ordinary 启动 | 留下拒绝回执；不生成任务、副本或扫描器，不自动切换模式 |

| 不带 mode 的既有联合请求 | 保留原行为；旧任务返回 `workspace: null`，不追溯改写成普通或深度检查 |

R2 表示现有固定适配器可以受管调用、解析和清理，不等于 R3 检出效果验收。代码没有读取客户端声明的 R3 等级，也没有把当前小型合成对照集提升为 R3。S1 执行仍经过已有实时 Docker 控制与镜像／规则／数据库摘要核验。

## 任务固定与失败语义

接受请求时固定合同版本、模式、选定工具、各工具 `admissionIdentity`、S1 档位、任务秒数和零子模型请求。固定摘要沿用当前工具镜像、版本、规则或数据库身份。任务过程中生成另一模式的计划，不改变原任务；同一请求号更改模式或步骤会被拒绝，原内容重复提交只返回旧 ID。

创建副本前、每个步骤前重新核对原合同，子扫描准入时再次比较原摘要，最后由真实扫描执行器验证身份和 S1 条件。任一处变化都不启动该步骤。子扫描在建立记录前被拒绝时，父任务失败、步骤记为 `not-run`，不会留下“仍在运行”的假状态。

合同是控制数据。项目脱敏规则若改写任务模式、摘要或分页标识，结果明确拒绝；说明文字仍按原流程脱敏。报告继续以最多 6000 UTF-8 字节分页返回，命中保持待验证。
