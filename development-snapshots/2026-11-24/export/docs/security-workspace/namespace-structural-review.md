## 它记录什么

只处理新增命名空间规则的裸 `eval/exec` 双／三位置参数调用，从固定清单读取源码，核对源码摘要和完整调用范围，再记录三类线索：

| 线索 | 输出含义 | 保留的不确定性 |
| --- | --- | --- |
| 名称绑定 | 同一静态分析区域发现同名绑定或命名空间效果，或未观察到直接冲突 | 不证明运行时使用的就是内建函数 |
| 参数来源 | 观察到参数声明、局部重新赋值或字面表达式 | 不证明外部用户可控制输入 |
| 约束 | 在支持的直线流程中观察到固定集合的拒绝分支；支持范围外的语法会阻止这项条件证据 | 普通字符串语义仍未验证，固定集合成员也可能包含危险代码 |

所有结果均为 `unverified`。没有确认漏洞、消除警告、降低风险级别或改变正式处置状态的代码。

Python 的局部、全局与内建名称按作用域查找；直接名称相同不能证明调用对象身份。[Python 名称解析](https://docs.python.org/3.12/reference/executionmodel.html#resolution-of-names)。输出协议v2要求起止行列与绝对字节偏移六项一起匹配 AST 和固定源码；列采用 UTF-8字节偏移。[Python AST 位置定义](https://docs.python.org/3.12/library/ast.html#ast.AST)

## 首批支持范围

约束观察仅支持模块顶层普通函数里的直接调用语句。检查为 `if value not in (固定字符串, ...):`，拒绝分支终止函数；中间只允许简单字面量赋值等受限语句。变量改写、条件检查、回调、动态命名空间、装饰器、复杂默认值、注解、嵌套调用及类作用域保持未确定。

类型参数、动态执行引用、内建命名空间或其别名、全局／非局部声明等语法保守标为未确定。循环回边、导入、异常别名、模式捕获和lambda不被算作参数来源证明；`parameter-name-observed`只表示声明名称观察。

最终修正版还纳入定义头部的赋值表达式：函数默认值、注解、装饰器、返回注解，以及类的基类／关键字可能在外层产生绑定。`builtins`的任何直接或改名导入均记录为命名空间效果。未观察到直接冲突只是词法线索；其他导入副作用、间接修改内建对象及运行时回调仍未证明。

仅为没有非UTF-8编码声明的源码出具观察。通过标准库的编码检测核对前两行；UTF-7、Latin-1等声明、未知编码、BOM和孤立CR不生成观察，保留未匹配，避免把UTF-8字符串解析结果误认为实际文件语义。[编码检测](https://docs.python.org/3.12/library/tokenize.html#tokenize.detect_encoding)、[编码声明语义](https://docs.python.org/3.12/reference/lexical_analysis.html#encoding-declarations)。测试只编译UTF-7原始字节和字符串以核对语法差异，不执行其中代码。

测试另外区分求值顺序：`value = eval(value, scope)` 的赋值发生在调用后；函数默认参数表达式在定义环境求值，不属于函数体局部作用域。候选不因这些文本位置误判来源。

## 与原始告警并行保留

本批复用上轮26份源码与17／20候选规则的原生扫描回执，不重跑这些旧扫描，也没有新增独立准入样本。两份回执原有21条警告保持原样。新复核器只读取其中19条命名空间规则命中：完整集合约束的2条可补条件证据，其余17条保留未确定。两套规则所得19条结构观察相同，只计一次。源码及执行条件真值仍以[原来的固定算术运行记录](namespace-arity-rules.md)为限。

## 接入前仍需完成

现有生产收录路径把 Semgrep 调用简化为“文件:行”，新复核器需要完整的起止行列及字节偏移。接入前必须传递并保存这些位置与源码摘要；不能用同一行的另一处调用补证据。未知调用范围在离线输出中列入 `unmatchedAnchors`，整体状态为 partial。

独立正常／危险样本、运行时身份和外部输入的实际可达条件、复杂传播、别名与动态调用、同一执行点的多规则汇总及生产展示均待完成。离线条件证据不提升 R3。
