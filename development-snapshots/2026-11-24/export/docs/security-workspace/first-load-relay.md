# 首屏加载的验收中继修复

复现中，CSS 和入口 JavaScript 的空响应对应新建 SSH 连接失败，VM 内未记录到转发阶段。部分错误明确标记了密钥交换阶段，只有连接重置类别的记录保留具体子阶段未知。中继原先每条浏览器连接都重新进行一次 SSH 握手。

验收工具改为先建立一条专用 SSH 主连接，最多用八个 exec 通道转发浏览器连接。子通道禁止自行建立替代连接。主连接丢失时，当前访问失败，由操作者结束本轮验收并按原请求状态决定后续操作。私有 Unix socket 在工具退出时清理。

从导出目录运行工具前，先用已有的隔离验收准备流程创建新的 `stage.json`。参数指向本次验收目录，该目录会保存去掉查询参数的连接阶段日志。

```sh
python3 -B scripts/harness_acceptance_relay.py --stage-dir /absolute/path/to/acceptance-directory
```

默认随机选择本机回环端口。返回的 `/__qa_login` 地址只连接该临时 VM 实例。完成验收后，在终端输入一行结束工具，随后运行该轮 VM 实例的清理流程。

连接复用版本的 24 次六并发合成探针全部成功。Chrome 新访客首屏、侧栏计分首次读取、独立窗口及连续三次强制重新加载均通过，首末页仍分别为 8 和 1，总分为 9。故意断开主连接后，资源读取失败，未记录到 VM 转发阶段。

复核后补齐了启动中断及停止超时的清理保护。两项真实进程回归先复现清理失败，再确认修复版本能终止并回收主进程、移除控制目录。修订版另做了同样的 24 次真实 VM 合成探针。Chrome 结果来自清理修订前的连接复用版本。临时端口、控制目录和 VM 实例清理已核对。

计分查询入口会先补齐或迁移默认规则，因此探针中的 POST scores 查询具有潜在写入。本轮只涉及临时合成项目。固定原日志中的 read-only 名称用于保留执行记录，实际行为以该接口契约为准。

后续修订已加入二次等待超时处理，记录未确认退出的进程并返回失败。最多接纳十六个连接处理线程，同时最多运行八个 SSH 转发通道。最终修订的四项回归、二十四次合成探针和 Chrome 三次强制加载均通过。[加固结果](relay-hardening-results.json)

SSH 握手被重置的更底层触发原因仍待查。上次未捕获的侧栏首读失败也保留为历史未知。日常入口采用不同的连接路径，本轮结果只覆盖隔离验收中继。后续验收应使用这份工具，并保留实例独立、只读守卫和源码清单核对。


后续准入修订给排队连接设置五秒期限；超时返回 503，停止或已观测到客户端 EOF 时取消。排队请求最多缓存 64 KiB，放行后原样转发。缓存已满时不再读取更多数据，EOF 若位于未读数据之后，取消检测可能延至放行或五秒期限；不宣称所有断开都可立即发现。

七项本地中继回归、真实 VM 八通道占用下的取消/超时/排队放行，以及二十四次常规读取通过。guest /proc 精确匹配本轮 root 与端口的三个采样均为八个 worker，连接关闭后为零；这是采样与源代码上限的共同证据，不是持续实时监控所有 SSH 进程。中继停止回执记录峰值八个 exec 客户端及无剩余 PID。UI 未改变，本轮不重复 Chrome。

新增 scripts/harness_final_output.py 在诊断输出截断前，从完整捕获的 CLI stdout 统计 final，记录完整输出摘要和唯一 final 文本。四项采集回归包含“前后各一个 final、前部超出尾部范围”的反例；隔离 headless 实测计数为一，并核对到同一会话、同一轮且工具结果之后的 assistant 文本。十二项异常回执反例均被拒绝。原始合成会话回执仅本机限权保存，审查材料不含其全文。

本轮结果见 [准入与完整输出验收](relay-admission-results.json)。这些验收不关闭旧 SSH 重置底层根因、历史侧栏首读未知或 R3 检测质量门槛。


后续诊断修订区分排队阶段的客户端断开和准入后的 SSH exec 启动错误。临时文件或 exec 创建失败返回 502，记录阶段、错误类别和 errno，关闭临时 stderr 并释放许可；日志不保存异常正文。真实中继中注入一次合成启动失败后为 502，紧接着的正常登录为 303；二十四次读取、八通道排队和清理回归通过。这是进程内故障注入，不是声称耗尽了宿主或 VM 的真实资源。

final 与 assistant 的原文先在 guest 内存中精确比较，再对两份存储文本统一脱敏；不同原文即使脱敏成同一个占位符也会被拒绝。记录原文摘要和比较语义，不保存原文到这些字段。两项启动错误、九项采集/绑定及七项生命周期测试通过。隔离模型回答中的无害合成 token 标记实际触发脱敏，最终结构化结果、同会话关联及十五项异常回执反例通过。私密合成回执继续只在本机以 0600 保存，不发送原文做复审。

新结果见 [启动诊断与脱敏绑定修复](relay-start-binding-results.json)。这些修订仅影响隔离验收工具；日常插件没有部署变更。旧 SSH reset、历史侧栏首读失败和普通 R3 仍未关闭。
