# 快照一致性、规则事务与可取消解析候选

本轮处理 DS-UI-2、DS-RULES-2、POL-F5，延续前两轮候选修复。候选插件为 173 个程序文件，新增异步解析控制模块；日常 VM 保留已验收的 169 程序 / 16 规则。本轮不部署、不提交、不推送。

## 快照回包

演练台统计读取同时核对项目编号、读取代次和组件生命周期。切换时清除旧统计并取消旧读取；A→B→A、同项目反向回包、旧页签 onData 回调和卸载后的回包都不能覆盖当前项目。创建项目或刷新名册的迟到响应也保留用户后来选择的项目。源码工厂和实际构建 bundle 使用同一控制函数。

## 规则写入与恢复

规则正文、元数据、两个可选目标指令文件、备份的存在性/权限，以及激活状态在变更前记录到私有恢复日志。失败时回滚；回滚不完整时保留日志，状态显示未确认并禁止继续修改。原始备份失败会阻止激活，删除与重置的 I/O 失败同样触发回滚。临时日志从创建时即为私有权限，失败的部分复制会清理临时文件。

所有规则变更与恢复共用 SQLite `BEGIN IMMEDIATE` 跨进程互斥，进程退出由操作系统释放锁，不以手工删除活锁实现恢复。锁文件位于规则目录的 `.transaction-lock.db`，没有指令内容；运行期间应保留它。恢复日志 `.transaction.json` 可能包含原始指令内容，以 0600 保存，单文件前像上限 1 MiB、日志上限 12 MiB。非普通文件和 FIFO 明确拒绝，不阻塞等待。

恢复界面说明恢复对象，提交 POST、明确确认和同一事务 UUID。旧页面的事务编号不能恢复新事务。恢复前不显示可编辑表单。恢复入口不会执行日志中的命令，路径只接受固定的规则文件集合；不能读取日志或锁时保持未知，不自动重建。

日志支持进程中断后的恢复，不承诺底层磁盘永久损坏、断电持久性或绕过本协议的手工文件改写也能自动恢复。跨文件变更不是平台指令读取器的原子快照；异常或中断后的未确认状态应先恢复，再继续使用该规则。

## 联合审查的异步快照

同步 API 保留；联合任务改用异步捕获。两条路径共享遍历和结果构造，固定文件哈希、脱敏和排除结果保持一致。文件边界让出事件循环，Python AST / JavaScript 语法检查使用固定解析命令，源代码只作为 stdin 数据，不执行项目代码；已登记秘密的脱敏回调留在主进程。

取消和单调期限传给解析子进程。发送终止信号后必须观察 child close 才返回失败，并删除本次创建的半成品目录，不删除既有目录。如果副本清理本身失败，明确报告清理未确认，联合任务保持 unconfirmed 且阻断新的受管任务；不以“已取消”掩盖清理失败。

原有同步源码读取、运行预览和计划接口没有全部改为异步；同步 API 的文件大小、节点数、输出和解析时间限制保留。本轮修复的是联合执行中同步解析阻塞取消/整体期限的路径，不是所有文件系统调用的严格实时保证。

## 验收

使用临时项目、合成规则、真实解析子进程，以及规则进程中断、双进程恢复竞争、FIFO、状态写入/回滚错误等故障注入。500 文件测试覆盖取消和期限，不代表完整检测准确率。生产控制函数和钩子夹具不等于真实 Chrome/Harness UI 验收。

完整结果见 `snapshot-rules-results.json`。R3、完整工作区和 95 条真实项目发现仍未完成。
