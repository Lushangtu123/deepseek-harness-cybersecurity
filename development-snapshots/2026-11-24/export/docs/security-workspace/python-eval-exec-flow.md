## 字符串条件证据候选

候选核对器补入一种不同于有限值白名单的结构证据。单引号开头、单引号结尾且内部无单引号，否则立即返回，随后同一顺序块中进入 eval 或 exec。支持源码中相邻的拒绝分支与执行语句，以及 try 的第一条执行语句。检查之后改值、少一个条件、换成 and、分支未返回、额外调用及全局绑定均有反例测试。对于括号分组，分别保存原扫描定位行和实际动态执行行。

## 字符串条件证据收紧与日常部署

Terminal Claude Code 的只读固定源码复核发现：同一行的 `eval` 与 `exec` 可能共用行号，使条件证据关联到另一个执行点。新增先失败后通过的反例后，核对器要求关联语句跨度内只有一个动态执行调用，批处理及 Node 投影再次核对明确规则与实际执行函数。没有列级命中身份时，多个动态执行调用保留未知。
