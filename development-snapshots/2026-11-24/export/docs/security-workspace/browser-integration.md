## 测试环境现象

VM 的 SSH 服务拒绝端口转发，验收改用既有受管 SSH 命令通道转送固定路径的只读请求，没有修改 SSH 配置或网络隔离。浏览器控制台唯一错误为临时页面未提供 `favicon.ico` 而返回 404。

最初单独挂载联合面板时没有保留父级审计组件注入的样式，出现长哈希越过卡片的测试外壳现象。最终窄窗口验收采用产品实际的嵌套关系：完整审计组件内挂载联合面板，其样式和长文本换行正常。单独挂载时的视觉结果不计作正式布局验收。

只读转送进程输出中另有一次客户端断开连接导致的 `BrokenPipeError`；该进程缺少事件时间戳，无法确定对应哪次页面动作。此次 41 次后台请求均成功，未观察到因此造成的列表错误；保留为测试转送层现象，未归因为产品故障。

测试只操作临时合成项目，未读取或修改真实 Phishing 项目及其 95 条待验证发现。部署程序 157 项及扫描器清单的摘要与前一轮基线一致。候选程序未部署、提交或推送，本轮未改产品代码。
