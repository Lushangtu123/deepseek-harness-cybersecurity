# 普通检查规则组合候选

2026-11-03，组合候选保留现用 16 条规则的完整定义，追加 PHP 动态求值、PHP 对象反序列化和 Python 请求值到动态代码执行三条研究规则，共 19 条。早期六条规则候选是研究子集，其中未包含现用的 exec、SQL 和 Shell 等规则。本批通过追加方式避免用研究子集覆盖这些定义。[组合规则](ordinary-rules-combined.candidate.json) · [来源与组成摘要](combined-rules-provenance.json)

组合前检查规则 ID 唯一，保留的 16 条定义逐项相同。专用 VM 使用同一个 Semgrep 1.182.1 固定镜像，分别对现用规则和组合候选运行两组静态对照。测试在禁网、只读、限时容器中完成，读取扫描器真实 JSON 并经现有 Harness 解析器复查。四轮均无解析错误，临时输入和容器已清理，现用规则与扫描器清单摘要一致。[结构化结果](combined-rules-results.json)

| 48 个自建静态对照 | 预期阳性命中 | 阴性命中 | 预期阳性漏报 | 阴性未命中 | 未覆盖 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 现用 16 条 | 13 | 2 | 3 | 14 | 16 |
| 组合 19 条 | 21 | 2 | 3 | 22 | 0 |

新增 PHP 规则扫描了原先未覆盖的 16 个 PHP 文件，其中 8 个预期阳性命中、8 个阴性未命中。原 16 条规则在自建集的 15 处命中、OWASP 集的 53 处命中，均按规则 ID、文件、行列位置逐项保留。新增数据流规则在 OWASP 集产生 24 处补充命中，其中 9 个对应阳性文件、15 个对应阴性文件，作为单独口径记录。

自建对照只验证所声明静态检查的预期，仍有 3 个预期阳性漏报。OWASP Python CWE-94 的 53 个文件采用固定上游标签，是已经用于开发诊断的样本。组合候选中的原 eval 和 exec 仍命中全部 20 个阳性与 33 个阴性，追加数据流规则没有消除这项误报问题。不能把来源相同的两类命中当作独立核实。[OWASP 基线说明](r3-owasp-python.md)

组合规则尚未安装到日常 VM。现用运行时的 PHP 规则校验也仍待适配。R3 保持未通过，剩余条件在结构化结果中列为阻断项，包括 D-16 分类别质量门槛、带位置及适用条件的独立漏洞基准、独立集误报、Semgrep 与 Trivy DB 发布者证明和 PHP 运行准入。
