## 缺口与实现范围

原 `harness.python.eval`、`harness.python.exec` 只匹配一个参数。Python 的动态执行接口允许另传全局／局部命名空间；有这些参数也不能据此认定输入安全。[Python 3.12 官方接口](https://docs.python.org/3.12/library/functions.html#eval)

既有19条组合候选的数据流规则可以覆盖 `input()` 的直接对照，但没有把本批普通函数形参认作已建模来源。本批26个文件全部实际扫描且无解析错误，原16条和19候选均漏掉4个双／三参数主对照。

新增 `harness.python.dynamic-code-namespace`，明确列出裸 `eval/exec` 的2、3个位置参数模式。使用 WARNING、LOW、sink-only 和待核实元数据；不证明输入来源、实际名称绑定或约束有效性，也不自动抑制或确认发现。固定字符串也列入清单，因为本批目标是盘点执行点。[Semgrep 参数匹配语义](https://docs.semgrep.dev/writing-rules/pattern-syntax#function-calls)

- [17条候选](namespace-arity17.candidate.json)：原16条定义完整保留，追加1条。
- [20条候选](namespace-combined20.candidate.json)：既有19条定义完整保留，追加同一条。原19条文件没有修改。

## 能区分约束与绕过的运行对照

24份自写源码包含34个固定向量，在现有固定镜像的 Python 3.12.15 中运行，只使用普通字符串和无害算术：

- 完整固定集合约束：允许指定表达式，2个越界输入均在执行前被拒绝。
- 条件检查、检查后覆盖、检查后追加：两种操作各3种，共6个路径实际算出预定标记值。
- 固定映射选择：即便传入标记表达式，也只选择固定值。
- 同名普通函数：返回原字符串，没有动态执行帧；它们仍被新增规则报警。
- 显式内建名称／导入别名：观察到动态执行，扫描仍未命中。

探针绑定源码、协议和自身摘要，记录调用行和编译帧。上述向量直接调用测试函数，没有证明真实 HTTP 可达性、外部攻击者控制或实际系统影响；也不覆盖自定义对象、资源耗尽和一般安全性。两份 CPython 正常源码本批仅复用扫描，运行依据保留在[上一批正常路径证据](independent-normal-controls.md)。

运行探针的容器禁网、只读、UID65534、capabilities清空、NNP、seccomp，限制内存256MiB、32个进程、1 CPU。容器内配置15秒期限，VM父进程另有22秒等待上限及最终强制移除。探针期间165项程序与40个数据库逻辑摘要匹配，规则、镜像清单和卷集合匹配；临时目录及容器已清理。数据库检查只比较逻辑内容，不声称 SQLite 旁路文件零写入。

扫描使用另外的只读禁网容器（UID1000、768MiB、60秒输出期限），依据归档的启动代码和扫描回执核对；本批未重做全部隔离故障验收。宿主连接使用既有管理器的配置校验和固定 SSH 入口，本批没有请求或修改宿主完全访问设置。
