两次都报告扫描了 53 个文件且无解析错误。共同的 eval 口径在两套规则上均为 50% 检出、48.5% 阴性命中。现用两条规则合看命中全部样本，说明这一口径下无法区分阳性和阴性。候选规则集未包含现用 exec，整体替换会损失观察能力。当前结果维持待验证，不能从文件级命中推断实际可利用性。

## D-16 准入草案

- **可比较性**：同一上游提交和标签、同一引擎与配置、固定规则映射。解析失败、遗漏或截断分开计入未知，未知不得计入正确阴性。
- **回归条件**：对明确声明覆盖的语言与 CWE，逐类别列出检出、阴性命中和未知。发布候选的共同口径应保留既有阳性命中、减少或维持阴性命中，并单列每条被移除规则原先覆盖的样本。粗规则全报只能作为基线。
- **发布条件**：完成合并规则的独立留出验证，补齐逐位置核对和按语言、类别设定的最低质量门槛。此子集已经用于诊断，后续针对它调整规则后，须用另一份独立样本验收。当前只建立 Python CWE-94 文件级基线，D-16 数值门槛和 R3 仍待完成。
