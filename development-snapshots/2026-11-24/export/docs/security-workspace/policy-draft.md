# P0 策略、预算与风险规则

2026-11-03。本批为纯函数候选实现，尚未注册RPC、切换agent预设或部署。合成规则一致性不是实际漏洞检出效果校准。

## 模式与候选上限

| 字段 | 普通检查 | 深度检查 |
| --- | --- | --- |
| wire mode | ordinary | deep |
| 规划策略 | 规则式 | 模型辅助；当前预览仍只选择静态步骤 |
| 最低工具等级 | R3 | R2 |
| 隔离档位目录 | S1 | S1～S3；逐步核对所需最低档位 |
| 推荐agent预设 | personal-review | personal-joint |
| 总时长上限 | 360秒 | 900秒 |
| 步骤数 | 3 | 6 |
| 并发 | 1 | 1 |
| 模型请求 | 0 | 16 |
| 单请求输出tokens | 0 | 2048 |
| 总产物预留 | 8MiB | 8MiB |

原设计的normal在现有DTO中沿用ordinary；接入时统一转换。检查模式和日常/受限/联合/原版agent预设是不同概念。当前预设不改变，执行标记始终false，不授予新权限。

以上是P0当前组合的候选上限，参考既有联合任务的默认/最大时限及额度，不修改其执行参数。P2/P5增加工具时须带策略版本重新评估，不把这张表当全阶段最终预算。CPU、内存、进程和临时空间由后台显式声明，不根据未知VM容量猜默认值。

## 候选预算校验

父/子预算结构与Schema一致。每个子预算受父预算限制；所有步骤时长、产物预留、模型请求和最大输出tokens累计。追加或重试仍占同一任务额度。父期限取总时长和范围到期时间的较早者，剩余时间不足则候选不可用。

价格分known / unknown / not-applicable。unknown无论是否调用模型都进入needs-decision；免费步骤显式声明not-applicable。模型调用没有已确认价格同样保留决策。请求额度不是金额硬上限，即使known也不声称存在货币硬限额。

`assessWorkspaceBudget()` 的eligible-preview只说明声明的数值符合候选合同，返回`executionEnforced:false`。P1仍须原子预留、持久记录、不确定结果不退额度，并把期限与资源传到执行器。所有进程及副容器的开销必须计入；本轮纯函数尚未实现运行强制。

`previewWorkspacePlan()` 已附策略和预算结果。未声明预算时记录budget-not-declared；声明时步骤ID与选中工具一一对应。计划摘要绑定策略、预算和既有输入/工具身份，始终`executable:false`。

## 风险分类与排序

`rankWorkspaceFinding()` 复用显示合同的唯一排队谓词。不排队的问题不计算优先级。依赖、代码/配置、凭据、恶意代码分别使用B6的18条规则；配置复用代码规则。输出保留事实副本、规则、调整理由、缺失输入、临时标志和版本。

- unknown事实保留；另设保守排序输入，不把未知写成工具已证明high/public。
- 先收齐缺失输入，再算分类、缺资料下限和单一弱启发式上限。
- 独立高可信证据、复现或精确适用的利用事实，不被单个弱观察压低。KEV例外只属于依赖，可信恶意签名例外只属于恶意代码；其他类别的同名字段不起作用。
- 未覆盖时保留旧证据，允许新证据上调，不因缺覆盖降级。
- 排序为优先级、保守排序严重性、置信度、首次发现时间、稳定ID。未提供置信度排在已提供值之后，不伪造概率。
- 可信签名等枚举由通过验收的后台适配器及来源证据产生，模型文本或规则标题不能直接赋予该事实。

本轮不确认漏洞、不改变人工处置、不生成VEX、不重写95条发现。

后续[首批调度接入](mode-dispatch.md)已在既有联合后台增加独立的模式准入合同；普通仍因缺 R3 拒绝启动，深度首批仅接受就绪 S1 静态步骤。这里的 `assessWorkspaceBudget()` 和 `previewWorkspacePlan()` 仍是纯预览；新的分派合同没有把完整预算强制或原型页面标为已交付。

## EPSS 防抖

EPSS提供利用概率信息，不给出本项目的影响或适用性结论。[FIRST官方FAQ](https://www.first.org/epss/faq)

`updateEpssBand()`要求显式高/低阈值、回落观察期、最大数据年龄及连续样本间隔。没有默认全局阈值；测试数值只是合成夹具，D-07真实校准仍待完成。

有效高值立即升级；连续有效低值满观察期才回落。缺失、过期、未来、乱序样本不推进回落；中间区间或缺失间隔重置计时。状态绑定配置和算法版本摘要，配置变化重算同一有效样本、重置降级期；缺样本时不把旧分类盖成新配置结果。历史高档失效时保留但标待评估，不显示成当前概率已证实。
