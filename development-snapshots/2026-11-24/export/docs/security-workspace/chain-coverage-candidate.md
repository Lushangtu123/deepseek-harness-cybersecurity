# VM 安全工作区攻击链分页与计分说明

攻击链页顶部显示项目总分。阶段图、资产和命中明细显示当前页，每页默认 500 条。页面显示起止位置、记录总数和当前页计入分值。项目或刷新标记变化时回到第一页。失效的项目响应、翻页回调及范围不匹配的响应不能覆盖当前页。旧端点缺少分页范围时显示范围未确认。

攻击链在同一数据库操作中读取计分面板的全项目判定，再按记录时间和命中 ID 读取当前页。去重和规则上限使用全项目的命中记录。自建、停用和规则排除保留原分类。命中序号沿用整条链的顺序，项目已命中与缺失得分点也使用全量记录。

`scoreChain` 接受整数 `limit` 和 `offset`，默认 500 和 0，页长最多 2000。模型工具 `redteam_attack_chain` 暴露同一参数和 `coverage`。步骤与隧道仍走独立的查询口径，分页时无需累加。并发改动项目时，两次请求之间的记录位置可能变化，刷新后可以重新读取。

得分面板和攻击链分开展示达到规则上限与重复记录。报告的排除总数采用统一名称。验证使用合成数据，实际结果见 `chain-coverage-results.json`。
