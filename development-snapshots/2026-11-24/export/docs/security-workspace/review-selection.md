# R3 样本选择资格核对

2026-11-11，离线评估器修复了一处计分缺口。旧实现只核对漏洞真值字段，忽略 `selection` 中的定向选择、非盲测和不计准入声明。这会让已知漏洞及补丁配对进入合格数量和指标分母。

修订要求行级选择声明提供方法、盲测与资格标志，以及选样协议摘要。明确不合格或已知定向配对的样本只计入诊断。缺少依据的旧输入也可读取，报告会列出不完整原因，合格指标排除这些记录。数据集摘要继续绑定全部选择声明，冻结后的修改会产生不匹配。报告版本更新为 4，输入版本保持 2。

四项新增回归在旧实现下失败，修订后 Mac 和 VM 各 27 项专项通过，Mac 全部 1,004 项插件回归通过。回放已用的 Xinference 扫描输出时，原始旧数据的合格数量从 2 降至 0，诊断数量仍为 2。回放脚本核对旧评估器摘要，并逐项比较原有阻断原因全部保留。旧冻结、历史报告和来源台账继续保留。该回放使用历史结果，没有新增独立检测样本。

VM 测试目录已清理，日常 169 项程序、42 项目库逻辑摘要及关键配置核对一致。Claude Opus 5.5 high 完成本轮复审。

后续仍需冻结复核器完整依赖，核对预先确定的取样协议，并收集代表性的独立正负样本。协议摘要和选择字段属于声明，其格式正确不代表实际样本独立。普通检查的 R3 质量准入仍待完成。
