# 计分一致性修复候选

状态：本轮限定修复范围的验收及最终外部复核已完成，尚未部署日常 VM；结果见 scoring-consistency-results.json。仅处理 SCORE-REVIEW-01/02/03 及补齐 SDK 条件导出回归。

面板、报告、攻击链向共享 evaluateScoreBoard 传原始档位及倍率；共享入口通过 hitPointsOf 统一应用一次倍率，再执行现有封顶和去重算法。展示层仍显示有效分值。没有调整规则上限、去重键、同分优先顺序或档位准入。

攻击链读取原始 hit_points，使用同一元数据回落逻辑，保留历史0，空值/null仍回落默认分；新增0分API仍拒绝。未填写内部code的自建点按point_id取得每行默认值，避免依赖code映射丢失默认分；多个无code点的默认分互不串用。报告排除分成自建、停用、封顶/去重三个互斥类别；标题避免把规则上限错误写成重复记录。

沿用既有共享函数和数据库，不新增依赖。零值默认的语言语义参见 [ECMAScript ToBoolean](https://tc39.es/ecma262/multipage/abstract-operations.html#sec-toboolean)；本修复复用 hitPointsOf 的显式空值判定，不使用零值的布尔回落。
