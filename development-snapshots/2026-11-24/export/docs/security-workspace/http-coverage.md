# 日常入口 HTTP 覆盖验收

本工具针对归属核对通过的既有日常入口 `http://127.0.0.1:49226`，按固定清单读取三轮：首页与四个主要 `/assets/` JavaScript/CSS 包，共十五个选中 GET。登录 GET 另计，正常为 303。没有服务重启、配置修改、插件部署或自动重试。

每轮核对核心引用集合、请求集合与数量、MIME、字节数及 SHA-256。资源漏选、额外或同数量替换、200 HTML 回退、失败状态、摘要变化或缺轮都不能通过。HTMLParser 识别 script 与 JS/CSS link 引用，包括 preload/prefetch；注释和内联脚本文本不当作资源。首页必须使用可核对 Content-Length 或完整 chunked；拒绝长度不明的关闭定界响应，是本验收的严格规则，不表示这种 HTTP 响应本身违反协议。重复/冲突长度头和未完成分块也拒绝。

四个核心资源摘要来自已归档的 2026-11-08 观测，修订实测仍匹配，不是上游签名证明。命令行不仅比较调用者给出的摘要，还将其绑定源码中的 `BASELINE_CONTRACT_SHA256`；即使另一个缩减清单与自己的摘要自洽，也不能作为本轮门禁通过。库函数保留参数化用于合成夹具，不能单独替代命令行的基线选择约束。未来构建有意变化时，需要核对来源、同时更新清单与固定摘要并重新复审，不从当次页面自动生成更宽松的清单。

```sh
python3 -B scripts/harness_http_coverage.py \
  --contract docs/security-workspace/daily-http-contract.candidate.json \
  --contract-sha256 <已核对且与源码固定值一致的清单摘要> \
  --output /absolute/new/path/result.json
```

页面已知本地 base `./`、三个启动 script 与两条 `/plugins/` preload 提示分别登记。启动脚本路径唯一；预加载提示的重复以清单的显式 count=2 表达，并不表示重复执行脚本。queryPresent 检查问号分隔符，空 `?` 也算存在。查询值不保存；这些 bootstrap 脚本和提示的正文、参数语义及全部动态资源不在字节验证范围。未知 JS/CSS 引用或登记漏项/多项会失败。工具不跟随页面给出的外部 URL 或重定向，也不请求含查询的 bootstrap 地址。

结果文件以 O_EXCL/0600 创建，已有结果在管理器与网络操作前拒绝覆盖。登录 URL、Cookie、页面正文及 bootstrap 查询值不写入结果。成功退出 0，探测或清单失败 1，无法独占创建输出时 2。

本轮保留初始解析失败、预加载兼容失败和外部复审长度截断。原先宽松谓词的一个资源/六次读取假通过、额外 preload、空查询、重复脚本路径、无长度首页前缀都通过实际旧/新模块作合成对照。三十一项回归、真实十五次选中读取、防覆盖/错误摘要及自洽替代清单拒绝用例通过。[结果](http-coverage-results.json)

此结果只证明本次 HTTP 核心包与引用登记通过，不代表浏览器执行、完整插件、睡眠/冷启动矩阵、漏洞检测效果或全产品放行。旧 SSH reset、历史侧栏首读根因和普通 R3 仍待处理。UI 未改，本次不重复 Chrome。
