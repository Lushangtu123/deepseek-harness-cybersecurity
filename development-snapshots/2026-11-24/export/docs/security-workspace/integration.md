## 联调修复

首次真实链路已完成扫描和报告收录，但面向模型的共享任务投影漏掉新增覆盖字段。修复后的共享投影保留五项文件覆盖值，并仅转发已知的 Trivy 输入策略；旧任务缺少这些记录时返回空值。新增回归先复现遗漏，再覆盖 wait、status、任务分页及旧记录，沿用 6000 字节响应上限。真实 VM 链路复跑通过，680 项插件回归通过。

独立代码复核仅覆盖本次任务投影修复及相关测试，未报告实质问题。该复核未覆盖其他 S1 变更。

本轮验收覆盖后台 RPC、容器、结果收录、报告分页和清理。后续已完成[候选组件 Chrome 交互验收](browser-integration.md)，使用独立测试外壳读取另一临时合成项目的真实扫描记录，并完成[真实模型 API 工具往返](model-api-acceptance.md)。API 测试使用私有连接适配器，正式 Harness 原生聊天与工作台部署仍待验收。此轮后端的 47 条结果来自合成项目，均保持待核实。
