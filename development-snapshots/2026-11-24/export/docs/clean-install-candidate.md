# 独立 VM 的基础与专业安装验收

候选版从独立的 Ubuntu 24.04 ARM64 空白镜像启动。验收机使用独立磁盘和一次性 SSH 密钥。虚拟网络只允许通过宿主回环代理访问 Ubuntu、Node.js 和 npm 软件源。安装完成后关闭该代理。

在 VM 内核对 1,621 个导出文件后，实际运行基础安装和专业安装。专业安装前注册表和工作区目录为空，基础安装器写出的九项回执通过接续检查。专业安装导入六个固定镜像，Semgrep、Trivy、ZAP 的就绪检查通过。专业安装生成的网页配置保留了 `/home/purge/workspace` 默认工作区设置。重复安装被拒绝，已安装的配置和回执保持原样。

REA MCP 连接后列出 229 个工具，并完成合成 JavaScript 分析和 Ghidra 反编译。reverse-route 入口、CodeGraph 版本及 PentAGI 的离线工作镜像也通过了检查。PentAGI 服务、模型任务和真实项目扫描仍需各自验收。

配置交接修复通过 18 项专业回归、8 项基础回归和 DeepSeek V4.1 Flash high 复审。安装证据补齐后，Claude Opus 5.5 high 接受了基础安装、专业资产和合成工具检查的验收范围。原始复审意见及取证补充已留存。

2026-11-11 停机后重新启动独立 VM。来宾启动时间落在宿主的启动至就绪窗口内。网页服务、安全套接字和 Docker 恢复运行，173 个已安装程序文件匹配，专业配置仍保留默认工作区路径，工作区注册表仍为空。Claude Opus 5.5 high 复审通过。

2026-11-11，在 macOS 的 Chrome 中完成专业版首屏和刷新验收。登录前工作区注册表为空。首次进入自动建立一个默认工作区和空白会话，刷新后仍只有一条记录，工作区 ID 与磁盘目录一致。`dsh-context`、`dshmarket`、`dsh-purge` 和 `dsh-whale-widget` 均处于启用状态，刷新后继续显示启用。`dsh-purge` 详情显示 `1.1.77-personal.11`，五个组件均为 Running。

这次首装声明由用户明确确认。账号引导在未配置账号时会随刷新再次出现，可关闭后进入空白会话。临时入口提供网页连接，版本、存储和宿主管理数据未接入，因此页面显示相关状态暂不可用。

Claude Opus 5.5 high 接受了本轮界面验收。目录名中的 `personal.1` 是固定安装槽位，包内版本及 Chrome 显示均为 `1.1.77-personal.11`。程序身份依据保留的安装清单与此前来宾摘要检查，网页中继依据文件路径与取证时摘要。运行瞬间的完整文件摘要未另外留存。测试标签、临时入口、验收 VM 及其测试密钥已清理。日常 VM 发布、模型与扫描任务以及独立 R3 质量验收仍各自待完成。
